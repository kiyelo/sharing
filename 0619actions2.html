✅ 실행 체크리스트

개인사업자~쇼피가입 액션 아이템

1 실행 순서

  1. 홈택스에서 개인사업자 신청
  2. 주업종을 전자상거래 소매업 525101로 등록
  3. 부업종을 국내외 온라인 판매 전반으로 폭넓게 추가
  4. 사업자등록증 PDF 저장
  5. 네이버 스마트스토어센터 사업자 판매자 가입
  6. 스마트스토어 URL 확보
  7. 구매안전서비스 이용확인증 발급
  8. 정부24에서 통신판매업 신고
  9. 통신판매업 신고증/신고번호 저장
  10. Shopee Korea Seller Centre 입점 신청
  11. 쇼피 승인 후 셀러센터 로그인

2 홈택스에서 개인사업자 신청

2-1. 기본 설정

항목입력값
사업자 유형개인사업자
과세 유형간이과세자 우선
사업장 주소실장님이 사용할 주소
개업일신청일 또는 실제 시작일

2-2. 주업종 설정

항목입력값
주업태도매 및 소매업
주종목전자상거래 소매업
주업종코드525101

2-3. 부업종 설정

  • 해외직구대행업 525105 추가
  • 홈택스 업종 검색에서 통신판매 / 온라인 판매 / 전자상거래 / 무점포 소매 / 상품중개 / 무역 / 수출입 / 생활용품 / 잡화 / 화장품 / 식품 관련 부업종을 가능한 범위에서 추가
  • 지금 판매 품목이 완전히 확정되지 않았으므로, 제외하기보다 국내외 온라인 판매 전반을 넓게 커버하도록 추가
  • 주업종은 계속 전자상거래 소매업 525101로 둔다.

2-4. 사업자등록 신청 후

  • 사업자등록증 PDF 저장
  • 대표자 신분증 파일 준비
  • 사업자용 이메일 준비
  • 사업자용 휴대폰 번호 준비
  • 정산 받을 은행 계좌 준비

3 구매안전서비스 이용확인증

3-1. 발급 방법

  • 네이버 스마트스토어센터 접속
  • 사업자 판매자로 가입
  • 사업자등록증 정보 입력
  • 대표자 정보 입력
  • 정산 계좌 입력
  • 스마트스토어 이름 입력
  • 스마트스토어 URL 확보
  • 관리자 메뉴에서 구매안전서비스 이용확인증 발급
  • 확인증 PDF 저장

3-2. 주안점

  • 스마트스토어는 통신판매업 신고용 URL과 구매안전서비스 이용확인증 발급용으로 먼저 사용
  • 스마트스토어에서 실제 상품 판매를 바로 시작할 필요는 없음
  • 확인증 파일은 통신판매업 신고 첨부자료로 사용

4 통신판매업 신고

4-1. 신고 경로

  • 정부24 접속
  • 통신판매업 신고 검색
  • 사업장 주소 기준 관할 시·군·구청으로 온라인 신고

4-2. 신고 입력 방향

항목입력값
상호사업자등록증과 동일
사업자등록번호사업자등록증 기준
판매 방식인터넷 / 온라인 / 오픈마켓 판매
취급 품목생활용품, 잡화, 뷰티용품, 화장품, 식품, 기타 온라인 판매 상품
인터넷 도메인네이버 스마트스토어 URL 또는 쇼피 상점 URL

4-3. 완료 후

  • 통신판매업 신고증 PDF 저장
  • 통신판매업 신고번호 저장
  • 신고번호를 사업자 자료 폴더에 기록

5 Shopee Korea Seller Centre 입점 신청

5-1. 준비물

  • 사업자등록증 PDF
  • 대표자 신분증 파일
  • 사업자 이메일
  • 사업자 휴대폰 번호
  • 정산 계좌 정보
  • 영문 상점명
  • 상점 로고 이미지
  • 영문 상점 소개문
  • 판매 예정 상품군 설명
  • 통신판매업 신고번호

5-2. 신청 순서

  • Shopee Korea Seller Centre 접속
  • 가입/입점 신청 시작
  • 이메일 인증
  • 휴대폰 인증
  • 사업자 정보 입력
  • 사업자등록증 업로드
  • 대표자 정보 입력
  • 대표자 신분증 업로드
  • 상점명 입력
  • 상점 로고 업로드
  • 상점 소개문 입력
  • 판매 예정 상품군 입력
  • 1차 판매 국가는 싱가포르로 설정
  • 신청서 제출
  • 승인 메일 확인
  • 승인 후 셀러센터 로그인
